# Elveo – GitHub Pages

Diese Version basiert **direkt auf dem zuletzt gelieferten HTML-Code**. Am bestehenden HTML/CSS/JavaScript wurde nur das für die Veröffentlichung notwendige ergänzt:

- Favicon
- Apple Touch Icon für „Zum Home-Bildschirm“ auf iPhone/iPad
- Web-App-Manifest
- PWA-Metadaten
- App-Icons in 192×192 und 512×512
- Elveo-Logo als SVG

## GitHub Pages

Alle Dateien in das Repository laden und unter **Settings → Pages** die Veröffentlichung über den gewünschten Branch aktivieren.

## iPhone

In Safari öffnen → Teilen → **Zum Home-Bildschirm**. Das neue Elveo-Symbol wird als App-Icon verwendet.
